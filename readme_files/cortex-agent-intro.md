# Introduction to Snowflake Cortex Agents

Snowflake Cortex brings industry-leading Large Language Models (LLMs) directly to your data. A Cortex Agent is a specialized application built on top of these models to perform specific tasks, such as answering questions, summarizing text, or extracting data.

## Why use Cortex Agents?
By bringing the compute (AI) to the data, Cortex ensures that your enterprise data never leaves Snowflake's secure perimeter. This solves massive data governance and privacy challenges.

## Key Capabilities
- **Cortex Search**: Hybrid search over unstructured documents.
- **Cortex Analyst**: Natural language to SQL generation.
- **LLM Functions**: Native SQL functions like `SNOWFLAKE.CORTEX.SUMMARIZE`.
